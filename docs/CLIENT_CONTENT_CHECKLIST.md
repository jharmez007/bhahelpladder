# Client content checklist

The current website uses only the draft business information supplied for Phase 1. Before launch, BHA Help Ladder should review or provide:

- [ ] Original logo asset (preferably SVG or a high-resolution transparent PNG). Place it under `public/images/` and set `BHA_LOGO_PATH` to the public-relative path, for example `images/bha-logo.png`.
- [ ] Public contact email for `BHA_CONTACT_EMAIL`.
- [ ] Public telephone number for `BHA_PHONE`, if it should appear online.
- [ ] Approved public address for `BHA_ADDRESS`, if it should appear online.
- [ ] Approved professional biography and portrait for Olamide Olaoluwa Ijaduola.
- [ ] Verified qualifications, accreditations and professional memberships, if any are to be published.
- [ ] Confirmation of service wording and which services are currently available.
- [ ] Approved email sender and reply-to details.
- [ ] Safeguarding and consent process for child-related requests before enabling any direct minor pathway.
- [ ] Emergency wording and locally approved emergency resources; none have been invented in this version.

Do not add testimonials, success rates, prices, credentials or contact details until they are supplied and approved.
